# 🍔 Food Delivery Website

A full-stack **Food Delivery Web Application** that allows users to browse food items, place orders, and make secure online payments. The platform includes authentication, cart management, order processing, and an admin dashboard.

---

## 🚀 Features

### 👤 User Module
- User registration and login
- JWT-based authentication
- Browse food items
- Add/remove items from cart
- Quantity management
- Secure checkout
- Online payment using Razorpay
- View order summary

### 🛠️ Admin Module
- Admin authentication
- Add new food items
- Update food item details
- Delete food items
- View all user orders
- Manage food availability
